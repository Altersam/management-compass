# Альманах менеджера v6

Курс для руководителей по материалам лекций (папка «Исходники»). Три раздела:

- **Лекции.** 10 тем, 53 раздела — та же структура, что в исходных PDF. В каждом разделе тезис и интерактивные блоки: сравнения, кликабельные шаги и циклы, матрицы, таблицы, вкладки, карточки‑раскрытия, шкалы, чек‑листы самопроверки, тренажёры сортировки, мини‑кейсы и калькуляторы (результативность проекта и премирование, стоимость переключений, узкое место процесса).
- **Практика.** Путь из 10 тем: в каждой три урока растущей сложности («Основы» → «Применение» → «Ситуации») и испытание. 170 заданий восьми типов: верно/неверно, выбор, кейс, несколько ответов, пропуск, порядок, пары, группы. Три жизни на урок, ошибочное задание возвращается в конец, опыт (XP), дневная цель, серия дней, повторение пройденного и итоговый экзамен на время. Испытания — 12 пошаговых симуляций и экзамен по теме 1.
- **FAQ.** 29 частых управленческих вопросов: короткий ответ, причины, шаги, готовая фраза, ссылка на раздел лекции и на испытание.

Открыть сайт: https://altersam.github.io/management-compass/

## Устройство

Статическое приложение на нативных ES‑модулях, без сборки и фреймворков.

| Путь | Что там |
| --- | --- |
| `index.html` | Оболочка. Маршруты: `#/`, `#/lectures/3`, `#/practice`, `#/lesson/3.2`, `#/lesson/1.x`, `#/lesson/review`, `#/lesson/final`, `#/play/project`, `#/faq/no-time` |
| `assets/app.js` | Роутер, страницы, путь практики, учёт прочитанных разделов |
| `assets/blocks.js` | Рендер и интерактив блоков лекций |
| `assets/practice.js` | Движок уроков: очередь заданий, жизни, проверка ответов (`check` — чистая функция) |
| `assets/games/kit.js`, `assets/games/*.js` | Симуляции: бриф → поле → разбор. Правила — чистые функции |
| `assets/styles.css`, `assets/games/games.css` | Строгая дизайн‑система: нейтральная палитра, один акцент, тонкие линии |
| `content/course/t1.js … t10.js` | Тема: `sections` (лекция), `lessons` (3 урока), `boss` (испытания) |
| `content/faq.js`, `content/help.js` | FAQ: короткие ответы и полные разборы |
| `theory.html`, `trainer.html`, `modules/module-XX.html` и т. п. | Перенаправления со старых адресов (`#/theory`, `#/games`, `#/help` тоже работают) |

Прогресс — прочитанные разделы, уроки, опыт, дни активности и звёзды — хранится в `localStorage` под ключом `almanac:v6`.

## Команды

```bash
npm start              # локальный сервер на 127.0.0.1:4173
npm test               # логика симуляций, проверка ответов, серия дней, целостность контента
npm run lint:content   # типы блоков и заданий, ответы, связи тем, FAQ и испытаний
npm run test:browser   # Playwright: маршруты на телефоне и десктопе, блоки, урок, FAQ, симуляция
npm run test:a11y      # axe: все лекции, практика, уроки, FAQ и 12 симуляций
npm run build          # сборка в site/
```

## Как добавить контент

- **Блок лекции** — объект в `sections[i].blocks` темы. Тип: `text, key, stat, compare, steps, cycle, ladder, cards, matrix, table, tabs, scale, check, sort, quiz, calc`. Жирный текст — `**так**`.
- **Задание** — объект в `lessons[i].ex`: `{t: 'choice', q, opts, ok, why}`; для `case` добавьте `s` (ситуацию), для `fill` — `___` в вопросе, для `order` — `items` в правильном порядке, для `match` — `pairs`, для `classify` — `bins` и `items: [[текст, номер группы]]`.
- После правки запустите `npm run lint:content`.
