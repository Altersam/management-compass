# Альманах менеджера v5

Тренажёр управленческих навыков по материалам курса. Три раздела:

- **Теория.** 10 тем, в каждой 4 идеи. У каждой идеи одна мысль простыми словами, схема (сравнение, шаги, лестница, матрица, таблица или карточки), пример из жизни и вопрос на понимание.
- **Игры.** 12 коротких пошаговых игр на 5–8 минут. В каждой есть сюжет, цель, решения с последствиями и до трёх звёзд за результат.
- **Что делать, если…** 29 типовых ситуаций. Для каждой — почему так бывает, что сделать по шагам, готовая фраза, ссылка на игру и на теорию.

Открыть сайт: https://altersam.github.io/management-compass/

## Устройство

Статическое одностраничное приложение на нативных ES‑модулях, без сборки и без фреймворков.

| Путь | Что там |
| --- | --- |
| `index.html` | Оболочка. Маршруты: `#/`, `#/theory`, `#/theory/3`, `#/games`, `#/play/project`, `#/help`, `#/help/no-time` |
| `assets/app.js` | Роутер и страницы |
| `assets/styles.css` | Дизайн-система: цвета, кнопки, карточки, схемы теории, раздел ответов |
| `assets/vis.js`, `assets/art.js`, `assets/ui.js` | Схемы теории, иллюстрации, иконки, прогресс |
| `assets/games/kit.js` | Игровой движок: вступление → поле (HUD, подсказка, события) → итог со звёздами |
| `assets/games/*.js` | 12 игр. Правила — чистые функции `create / act / hud / board / result` |
| `content/topics.js`, `content/help.js`, `content/games.js` | Тексты теории, ответов и каталог игр |
| `assets/fonts` | Unbounded и Manrope (кириллица и латиница), подключены локально |
| `theory.html`, `trainer.html`, `modules/module-XX.html` и т. п. | Перенаправления со старых адресов |

Прогресс — звёзды за игры и пройденные вопросы — хранится в `localStorage` под ключом `almanac:v5`. Других данных сайт не сохраняет.

## Команды

```bash
npm start              # локальный сервер на 127.0.0.1:4173
npm test               # логика игр и целостность контента
npm run lint:content   # проверка ссылок между темами, ответами и играми
npm run test:browser   # Playwright: маршруты, телефон и десктоп, квиз, поиск, прохождение игры
npm run test:a11y      # axe: контраст и доступность главных страниц и всех игр
npm run build          # сборка в site/
```

## Как добавить ситуацию или идею

- **Ситуация.** Новый объект в `content/help.js`: `id`, `topic`, `title`, `why`, `steps`, `phrase`, `game`, `idea: [тема, номер идеи]`.
- **Идея в теории.** Объект в `ideas` нужной темы `content/topics.js`. Поле `vis.type` — одно из `compare`, `flow`, `ladder`, `cards`, `matrix`, `table`.
- После правки запустите `npm run lint:content`: он проверит связи между темами, ответами и играми.
