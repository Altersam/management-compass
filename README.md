# Альманах менеджера v7

Курс для руководителей по материалам лекций (папка «Исходники»). Три раздела:

- **Лекции.** 10 тем, 53 раздела — та же структура, что в исходных PDF. В каждом разделе тезис и интерактивные блоки: сравнения, кликабельные шаги и циклы, матрицы, таблицы, вкладки, карточки‑раскрытия, шкалы, чек‑листы самопроверки, тренажёры сортировки, мини‑кейсы и калькуляторы (результативность проекта и премирование, стоимость переключений, узкое место процесса).
- **Игры.** 13 пошаговых симуляций — по одной‑две на каждую тему курса. У каждой три уровня: «Знакомство» (щедрые ресурсы и подсказки), «Давление» (ресурсов меньше, другой случай) и «Мастер» (жёсткие ограничения, без подсказок). Следующий уровень открывается, когда набрано 2 звезды на предыдущем. Опыт начисляется за игру и за улучшение результата, есть дневная цель и серия дней. Тактильный слой: мягкие синтезированные звуки (выключаются кнопкой в шапке), лёгкая вибрация на телефоне, круги от нажатий, «прыгающие» числа и звёзды по одной.
- **FAQ.** 29 частых управленческих вопросов: короткий ответ, причины, шаги, готовая фраза, ссылка на раздел лекции и на испытание.

Открыть сайт: https://altersam.github.io/management-compass/

## Устройство

Статическое приложение на нативных ES‑модулях, без сборки и фреймворков.

| Путь | Что там |
| --- | --- |
| `index.html` | Оболочка. Маршруты: `#/`, `#/lectures/3`, `#/games`, `#/play/project/2` (игра и уровень 1–3), `#/faq/no-time` |
| `assets/app.js` | Роутер, страницы, каталог игр с уровнями, учёт прочитанных разделов |
| `assets/blocks.js` | Рендер и интерактив блоков лекций |
| `assets/juice.js` | Звуки (Web Audio, без файлов), вибрация, частицы и анимации обратной связи |
| `assets/games/kit.js`, `assets/games/*.js` | Симуляции: бриф → поле → разбор. Правила — чистые функции, `create(scenario, level)` и `levels` задают сложность |
| `assets/styles.css`, `assets/games/games.css` | Строгая дизайн‑система: нейтральная палитра, один акцент, тонкие линии |
| `content/course/t1.js … t10.js` | Тема: `sections` (лекция) и `games` (симуляции темы) |
| `content/faq.js`, `content/help.js` | FAQ: короткие ответы и полные разборы |
| `theory.html`, `trainer.html`, `modules/module-XX.html` и т. п. | Перенаправления со старых адресов (`#/theory`, `#/games`, `#/help` тоже работают) |

Прогресс — прочитанные разделы, опыт, дни активности и звёзды по уровням игр — хранится в `localStorage` под ключом `almanac:v6`.

## Команды

```bash
npm start              # локальный сервер на 127.0.0.1:4173
npm test               # логика и баланс уровней симуляций, серия дней, целостность контента
npm run lint:content   # типы блоков, ответы, связи тем, FAQ и игр
npm run test:browser   # Playwright: маршруты на телефоне и десктопе, блоки, уровни игр, FAQ
npm run test:a11y      # axe: все лекции, каталог игр, FAQ и 13 симуляций
npm run build          # сборка в site/
```

## Как добавить контент

- **Блок лекции** — объект в `sections[i].blocks` темы. Тип: `text, key, stat, compare, steps, cycle, ladder, cards, matrix, table, tabs, scale, check, sort, quiz, calc`. Жирный текст — `**так**`.
- **Игра** — модуль в `assets/games/` с `intro`, `levels` (3 строки), `scenarios`, `create(scenario, level)`, `act`, `hud`, `board`, `result`; запись в `content/games.js` и id в `games` нужной темы.
- После правки запустите `npm run lint:content`.
