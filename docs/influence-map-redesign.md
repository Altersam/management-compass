## Подход

Фиксированные HTML-узлы и тонкий SVG overlay, измеряемый по фактическим координатам узлов. Формальные линии нейтральные; реальные связи имеют стрелку, подпись и разный штрих/толщину. Наблюдение подсвечивает участников, но не создаёт связь. Desktop pointer drag — дополнение к выбору начала/конца кнопками. На телефоне связь имеет тот же текстовый и touch-путь.

Выбранный узел, открытый overlay, источник/цель связи и этап карты — локальное UI-состояние controller этой игры. Общая оболочка получает один optional mountUI hook с прежним default; существующие opt-out history/practiceCycle/quietStatus/renderReport используются повторно. Controller не является универсальным graph builder.

При недостаточной опоре implement показывает разрыв, сохраняя карту. Можно изменить участников/связи или открыть оставшийся след. Если исследование исчерпано, после разбора допускается явное завершение с зафиксированным разрывом; результат не объявляется успешным.

## Реализация и совместимость

`influence-map.js` — локальный controller только этой игры: разметка карты, измерение координат, SVG paths, labels, Pointer Events, клавиатура и ephemeral selection. Это не общий network framework. Общая ui.js вызывает optional mountUI и afterRender/dispose; другие модули продолжают использовать прежний render. Opt-out Metrics переиспользованы, её исходники и визуальная механика не менялись.

Формальные нейтральные линии обозначают схему ролей по должностным функциям, а не юридически установленное подчинение. Эксперт Анна помещён отдельно. Реальные стрелки накладываются только после действия игрока. У каждой связи есть текстовое from → type → to представление; SVG помечен aria-hidden. На mobile этот список открыт, desktop — раскрываемый fallback.

`implementationFeedback` — optional boolean только для незавершённой проверки опоры; старые saves не требуют его. Выбор/редактирование после feedback снимает прежнее сообщение, новая проверка снова использует неизменённый evaluate(). `finishReview` доступен после обнаружения разрыва: намеренно завершённая слабая опора остаётся слабой в отчёте. Бюджет, edges, coalition и unknown fields не уничтожаются.

Восстановление legacy state проверено до/после backup; выбранный director в старом сохранении отображается выбранным. Для нового create coalition пустая, что исключает подсказку «директор автоматически нужен». Внутренние from/to/kind и revision остаются прежними. Финальные inspections не пересоздают формы личного действия и не стирают введённый следующий шаг.
