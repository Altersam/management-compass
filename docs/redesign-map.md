# Карта педагогической переработки

## Что обнаружено до разработки

| Узел | Сейчас | Что меняется |
| --- | --- | --- |
| Главная (`index.html`, `course-home.js`) | Основной смысл создаёт JavaScript; три стартовых действия; десять одинаковых карточек; служебное описание освоения | Статический HTML с двумя сценариями и четырьмя смысловыми этапами; продолжение — небольшой вторичный элемент |
| Учебная страница (`course-lesson.js`) | Семь одинаковых шагов для всех тем; крупные проценты; чтение подтверждается «Понял» | Первой показывается живая ситуация; у каждой темы собственный рабочий объект; после объяснения — короткое решение с последствиями |
| Объяснения (`course-data.js`, `content.js`, `knowledge.js`) | «Результат / владелец / срок / контроль» повторяются как универсальный рецепт | В курсе идея развивается: своё время → поручение → право сотрудника → чужое подразделение → коалиция изменения. Подробные исходные объяснения сохраняются в справочнике |
| Адизес | Одинаковое раскрытие в каждом из трёх блоков и в связях | Один подходящий «Другой взгляд» на тему, без повторения на всех экранах |
| Вопросы (`course-questions.js`) | Правильный ответ часто длиннее; часть альтернатив заведомо слаба; варианты циклически переставлены | Правдоподобные короткие альтернативы, последствия; независимое перемешивание с сохранением канонического индекса ответа |
| Итог | Десять независимых вопросов, перенесённых из банка | История сервиса с меняющимися очередью, нагрузкой, ошибками, доверием и использованием; каждое решение меняет следующее условие |
| Перенос | Четыре поля, включая обязательное описание автоматической реакции; служебные подтверждения | Три поля: действие, место, дата; последующее «помогло / частично / не помогло» и причина |
| Дневник | Большая форма и одинаковые карточки записей | Список экспериментов по датам; прежние записи доступны отдельно, не удаляются |
| Навигатор | Симптом сразу ведёт к заранее заданному набору тем | Двенадцать бытовых формулировок → два-три уточнения → конкретная техника и объяснение выбора |
| Визуализации | Почти все схемы одинаково раскрывают подписи | Схемы остаются справочными; в курсе параметры меняют состояние дня, поручения, процесса, сообщения или сервиса |

## Сохранить

- Все десять тем, тридцать техник и их существующие идентификаторы.
- Рабочие шаблоны, исходные кейсы и расширенные объяснения справочника.
- Отдельные страницы Адизеса и литературу.
- Профили, ключ `management-compass:v1`, прежние заметки, ответы, попытки и экспорт.
- Проверки конфликта слияния, статическую публикацию, работу без внешних API.

## Объединить и вынести

- Правила пользования, хранение данных, импорт и профили — в настройки, а не в учебный текст.
- Учебные статусы — в возможность продолжить и небольшую полосу.
- Теорию и практическую ситуацию — через смысловой мост, а не повторение общего чек-листа.
- План применения и дневник — в один эксперимент с обратной связью после указанной даты.

## Различия механик

1. День: время, отвлечения, вытеснение задач.
2. Поручение: зависимость и момент проверки.
3. Самостоятельность: опыт, риск, границы.
4. Решение: постепенное раскрытие обстоятельств.
5. Сообщение: состав, порядок, тон, канал.
6. Подразделения: ресурс, право выбора, содержание эскалации.
7. Документ: версия, доведение, понимание, исполнение, приёмка.
8. Поток: работа, ожидание, возвраты, дополнительные проверки.
9. Изменение: разные причины отказа и разные меры поддержки.
10. Дашборд: границы метрики, скрытые запросы, альтернативы.

## Совместимость

Новые решения, микродействия, эксперименты и история симуляции добавляются к данным профиля. Старые записи и результаты не заменяются. Перестановка вариантов меняет только показ, а сохранённое значение остаётся каноническим индексом. Изменение раннего решения в симуляции пересчитывает продолжение: нельзя сохранять последствия из другой ветки.

## Проверка результата

- Без JavaScript видны название, два входа и структура курса.
- У всех десяти тем есть собственная причинная механика, а не только новый заголовок.
- Изменение параметра меняет вычисляемое состояние и объяснение.
- На мобильной ширине нет горизонтальной прокрутки документа.
- Старый профиль и резервная копия сохраняют заметки и рабочие формы.
- Вопросы не используют фиксированный первый ответ; перемешивание не изменяет правильность оценки.
- Итог зависит от истории, а выводы описывают решения в этой истории, не личность человека.
