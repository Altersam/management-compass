# «Проектный подход»: визуальный маршрут

Исходная модель изучена 11 октября 2026: contexts/blocks/presets, evaluateLegacy/evaluate, experiment и два runs. Формулы и modelVersion 2 / revision 1 сохраняются. У каждого нового run есть обычный result и pressure одного фиксированного внешнего изменения; сравнение обоих маршрутов на одинаковых условиях не заменяется confound «изменение только во второй попытке».

Три сценария выбираются строками. Маршрут центральный, palette ниже. Добавление/перемещение/удаление и пустой маршрут используют прежние add/move/remove; presets — исходные композиции. До run показываются только дни блоков. Трасса — сохранённые start/end/work/rework/wait; старым trace без этих полей не приписываются выдуманные причины интервалов.

## Реализация и границы

`hybrid-route.js` использует прежний mountUI hook без общей миграции приложения. UI selection локальна. Формулы evaluate/experiment/legacy calculation, два runs и их validation/report не менялись. Старый renderer сохранён как compatibility API, но активная страница использует новый constructor.

Сценарии раскрывают uncertainty, стоимость дня и обязательность внешней проверки. Стартовые Waterfall/Agile/Hybrid — шаблоны в details; пустой маршрут очищается прежними remove. Добавление из palette, удаление и перестановка имеют pointer и кнопочный путь. Число блоков не превышает прежние 14.

После первого run появляется сохранённое внешнее event и менее заметный первый маршрут. Его текст не сделан полупрозрачным до потери контраста: приглушены поверхность и линия. Второй план изменяется под ним. Оба результата проверяются на обычных условиях и одном внешнем изменении, поэтому сравнение причинно сопоставимо.

Финал показывает две трассы на общей шкале, работу/переделку/ожидание с текстовыми значениями и фактические позиции review/pilot. Наличие блока review не выдаётся за подтверждённую потребность автоматически: исходные effect/feedback сохраняются в «Почему». Количество дней разработки до позднего эффекта — сумма исходных build, не прогноз реальной организации. Для legacy без pressure и разбивки trace показываются сохранённые интервалы, с указанием ограничения.

Смысл: метода-победителя нет; gate/test/release и стоимость обратной связи остаются ограничениями сценария. До run точная переделка/quality не раскрываются.

Проверки итогового набора: **150 Node / 101 browser / 28 a11y**, lint/build/diff успешны. Прежние tests охватывают все contexts, 50 seeds, актуальность test/gate, release last, external window, deterministic two-run comparison и legacy calculation. Новые browser paths — context rows, pointer reorder, пустой маршрут, repeated blocks, кнопочный keyboard путь, resume и narrative review. Сохранилась проверка corrupt-save без перезаписи.
