Новые проверки — `tests/detective.test.cjs`, `tests/browser/detective.spec.cjs`; существующие content lint и a11y дополнены проверками детектива.

Детектив хранит `course.detectiveGame` (revision 1) и `course.detectiveGameArchive`. Проектная игра, старая simulation, профили и действия не переиспользуются как состояние нового движка. Диагностические результаты считают интервал и качество тех же пяти случаев; повторное чтение не расходует бюджет, а повторный одинаковый пилот не даёт фиктивного нового результата.

Финальные проверки 3.3: **85 Node / 42 browser / 5 a11y**, content lint и build успешны, diff check и Git integrity без ошибок. Случайные интервалы проверены на 50 seeds, мобильный путь и шесть ширин — browser tests. Дизайн и самоаудит — `docs/detective-design.md`, `docs/detective-ux-audit.md`.

При публикации включить **все новые untracked файлы детектива, каталог и их entry/styles/tests/docs** вместе с изменением shell и package/lock. Без `games.html` новый пункт меню будет вести на отсутствующую страницу; без отдельных модулей игра не запустится. Build и import/link lint проверяют комплект локальных файлов, но не заменяют включение файлов в commit.
