# «Испорченный телефон»: видимая передача смысла

Изучена исходная модель: пять hops, четыре канала, бюджет 18, подтверждение +2, action/deadline/quality/resource, irreversible losses, обязательная форма executor, transfers до/после. Create/act/validate/parts/hops/report сохраняются. UI показывает шесть участников, текущий переход и четыре смысловых жетона; канал выбирается кнопками. Пройденные звенья раскрывают собственные transfer, не общий длинный history. Конечный получатель не выдумывается, если бюджет закончился раньше него.
