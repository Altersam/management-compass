# «Испорченный телефон»: видимая передача смысла

Изучена исходная модель: пять hops, четыре канала, бюджет 18, подтверждение +2, action/deadline/quality/resource, irreversible losses, обязательная форма executor, transfers до/после. Create/act/validate/parts/hops/report сохраняются. UI показывает шесть участников, текущий переход и четыре смысловых жетона; канал выбирается кнопками. Пройденные звенья раскрывают собственные transfer, не общий длинный history. Конечный получатель не выдумывается, если бюджет закончился раньше него.

## Реализация и аудит

`telephone-chain.js` — renderer этой цепочки и короткая 180ms state-анимация после send, отключаемая reduced-motion. Для канала и confirm используются прежние действия общей оболочки. Новых persisted полей нет; old saves читаются с прежними message/transfers/formal.

Четыре жетона показывают сохранность смысла и ✕ при потере. Click/Enter раскрывает исходный текст — hover не обязателен. Пройденный участник хранит канал, confirm и только новые потери его перехода. Общий history выключен существующим opt-out.

Перед отправкой одна контекстная строка, без длинной лекции. Чат/письмо/документ/разговор выбираются кнопками, проверка понимания отдельно checkbox. Специфика обязательной формы объясняется после реально достигнутого перехода и в финале; поздний документ или confirm не восстанавливают утраченное автоматически.

Финал сравнивает исходное поручение и реально дошедший смысл по четырём частям, затем находит первый before=true → after=false transfer. При budget ending до 5 hops заголовок называет фактического промежуточного получателя, не объявляет успешную доставку конечному.

Проверки итогового набора: **150 Node / 101 browser / 28 a11y**, lint/build/diff успешны. Старые engine tests сохранены. Проверены channel costs, confirm, complex/formal hop, irreversible loss, early exhaustion, legacy state/reload, keyboard, accessible раскрытие текста и mobile. UI не содержит select; единственная форма — submit «Передать» и свёрнутый перенос рабочего действия после результата.
