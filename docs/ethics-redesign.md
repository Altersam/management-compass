Свободный note не анализируется: ограничение 2000 символов, минимум 10 перед завершением. Прежние завершённые попытки и архивы остаются читаемыми.

## Новый цикл

Досье → факты → решение → защита объективности → объяснение → разбор. Вход содержит одну игровую кнопку. Личная связь открывается источником, а не вводным абзацем. Решения выбираются текстовыми строками; textarea появляется после них. Optional casework хранит только этап интерфейса, активный источник и одну мягкую попытку пересмотра. Legacy defaults выводятся из checks/history/note без сброса данных.

При слабом основании или незащищённой замеченной личной связи предложение пересмотра сохраняет все факты и текст. После одной попытки игрок может явно завершить с выбранным основанием; разбор не подменяет его другим решением.
