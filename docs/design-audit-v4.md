Просмотрены все 27 HTML-входов, перечисленные в задании, shell/themes/almanac/styles/experience/course/games CSS, три игровых stylesheet, home/theory/games/workspace/trainer entry, chapter/course-lesson/navigator/experiments/app renderers. ## Страницы и главная задача

- `index`: выбор режима; обложка + индекс, serif title, feature с Gantt.
- `theory`: выбор темы; оглавление с компактным поиском. Counts не несут пользы. Схемы оставить index слева / рисунок справа, lazy и deep links.
- `module-01…10`: чтение / применение; конкретное introduction, ширина 74ch, содержание на полях, glossary без панели. Canonical IDs сохраняются.
- `games`: выбор механики; без поиска при 12 играх. Две featured игры, остальные строки с мини-моделью и временем.
- `game`: играть; HUD и Gantt главные, команда и события в боковых колонках, настройка в drawer. DnD/checkbox/keyboard, autopause и причинный review уже есть. Текущий нормальный темп 4 s/четверть дня: сделать 2 s, не менять model tick.
- `detective`: расследовать; источники / цепочка / заметки. Убрать панели вокруг колонок, сохранить dossiers/evidence как реальные объекты.
- `trainer`: разные композиции уже существуют (route/table/network/files/queue/backlog); CSS унифицирует их чрезмерно. Усилить различия без reducer/formula rewrite.
- `learn`: сценарий и практика; интерактивные объекты уже разные. Навигация семи подэтапов прячет иерархию: четыре группы, подробности доступны отдельно.
- `workspace/navigator`: описать проблему; compact hypothesis/check/alternative/first move. Старые hash-входы продолжают открывать один режим.
- `workspace#modules`: применить технику; индекс по теме, поиск по всему набору, избранное.
- `workspace#diary`: вернуться к наблюдению; три основных поля, metadata вторична, без новой обязательной оценки. Старые ratings сохраняются при редактировании.
- `experiments`: список открытых действий, новая запись по запросу; гипотеза вторична, перенос черновика из игры сохранён.
- `settings`: профиль / оформление / копия / хранение; подробности privacy здесь.
- `sources/adizes`: библиография и три идеи, не набор theory cards; оговорки о моделях сохраняются.

## Текст и дубли

Точные частоты будут записаны в отчёт нового `scripts/design-report.cjs` до редакторских изменений и после них. `rg` в окружении отсутствует; поэтому отчёт использует публичный allowlist и AST-like извлечение строк, отдельно отмечая ограничение статического анализа. Он не включает tests/docs/sync-copy и не объявляет внутренние property names пользовательским текстом.

Content schema/adapter/depth/guide содержат авторские объяснения, canonical вопросы и схемы; они не требуют сокращения до карточек. Редактура затрагивает обрамление/labels и очевидные повторы, а не полноту теории. Изученные прежние design/docs описывают 3.x и сохраняются как история.

По поиску ссылок `(2)` не найдено runtime-import на sync-copy. Есть упоминания в документации и тестах exclusion; это не потребители файлов. Сравнение идентичности и конкретный список решений обязательны перед cleanup. Никакие дубли этим аудитом не удалены.

## Проверка и границы

После каждого этапа: `npm test`, `npm run lint:content`, `npm run test:browser`, `npm run build`, `git diff --check`. При изменении contract UI тесты обновляются по поведению, а не удаляются. Финал: axe в обеих темах, screenshots 1440×1000 / 1024×768 / 390×844 по 11 маршрутам, self-audit cards/pills/radii/CTA/copy/legacy.

Ключ данных, dataVersion, IDs, canonical ответы, export/import, архивы, модели и retrieval остаются совместимыми. Никакой framework-миграции. Cleanup готовится отдельным набором; агент не создаёт коммит без явного запроса.
